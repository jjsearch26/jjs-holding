# JJS holding page

Published at https://jjs-holding.pages.dev/ from the main branch. No build command; publish repository root.

Portrait mobile screens use the user-approved Austin rooftop film, with its original soundtrack. Desktop uses stabilized Austin landscape footage, the original vector JJS logo composited at output resolution, January 2027, a gentle thirty-second push-in, and muffled traffic with a distant siren.

Both layouts fill the viewport without stretching. Video autoplays muted and loops; Sound on enables audio. Reduced-motion visitors and browsers blocking autoplay can start playback with Play video.
